# tudu 📓
a to do app :)

- Feito como atividade 5 do Bootcamp Dev Full-Stack Junior da +PraTI, consiste em um "To do App" com as funcionalidades de adicionar, editar, excluir e salvar tarefas.

# 📒 Foram utilizados:
- Bootstrap (em alguns elementos).
- Figma (design).
- Css.
- JS.
- Html.

- Faça download para acessar na sua máquina, ou clique no link a seguir: https://tudu-sepia.vercel.app/

- Obs: Para editar uma tarefa deve clicar no título da mesma, aproveite. ☺️
